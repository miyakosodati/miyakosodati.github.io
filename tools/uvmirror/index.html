MYS Tools / UVMirror

MYS UVMirror v1.0.0

頂点番号を変えない UV ミラー — スキンウェイトもブレンドシェイプも無傷のまま、UV だけを左右対称に
Maya 2020–2026 Windows 外部依存なし 無償・商用利用可
ダウンロード（v1.0.0）
ダウンロード・使用により使用許諾契約（EULA）に同意したものとみなされます。社外への再配布はできません。

できること

  • 従来の「半分削除 → ミラー → マージ」は頂点番号が総入れ替えになり、スキンウェイトやブレンドシェイプ、書き出し済みキャッシュが壊れます。UVMirror はジオメトリに一切触れず UV 配列だけを書き換えるため、頂点番号・フェース番号・スキン・ブレンドシェイプすべて無傷です。
  • メッシュ全体でも、選択したコンポーネントだけの部分ミラーでも。フェース選択なら面単位、頂点・エッジ・UV 選択なら頂点単位で反映され、左右どちら側を選んでも同じ結果になります。
  • UV モードは2種類。「重ねる」で左右 1 枚のテクスチャを共有、「U 軸で反転」で左右を別領域に描き分け。U オフセット 1.0 で隣の UDIM タイルへの振り分けもできます。
  • 左右対応はバインドポーズの座標から取るため、ポーズ中やブレンドシェイプ変形中でも正しくミラーできます。対応が取れなかった箇所は診断リストに列挙され、「Maya で選択」でそのまま確認できます。

配布物zip 1ファイル（ドラッグ&ドロップインストーラ同梱）

入れかた

Maya を起動し、zip を展開したフォルダの install_MYS_UVMirror.py をビューポートへドラッグ&ドロップするだけです。ファイルのコピーとシェルフボタンの作成まで自動で行われ、再起動なしでそのまま使えます。

手動でインストールする場合の手順は、同梱の README.txt にまとめてあります。アンインストールはコピーされたファイルとシェルフボタンを削除するだけです。

承知しておきたいこと

  • 履歴のあるメッシュへは履歴経由で書き込むため Ctrl+Z でそのまま戻せます。履歴のないメッシュのみ API 直接書き込みとなり、その場合はツール内の「元に戻す」ボタンで実行前の UV に復元してください（自動でバックアップされています）。
  • 左右対応は頂点の位置から取ります。左右の位置ずれが大きいモデルでは「位置許容誤差」を調整してください。対応が取れなかった箇所は診断リストに表示されます。
