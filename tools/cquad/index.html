できること

  • AI 生成モデルや三角化されたデータなど、三角ポリゴンだらけのメッシュを、Maya 標準の四角化（Quadrangulate）より素直な形で四角にまとめます。
  • めざしているのは完璧な四角化ではなく「程よい」四角化です。形のきれいな所はしっかり四角にし、無理に四角にすると歪む所は三角のまま残します。ループの流れを作り直すリトポとは別物で、手直しの土台を手早く作るためのツールです。
  • 隣り合う三角の組み合わせを、四角にしたときの形のきれいさ（内角が 90° に近いか / 平らか / 辺の長さの偏り）で採点し、メッシュ全体でよい組み合わせから順に決めます。余った三角も、組み替えで拾える分はできるだけ四角にします。
  • 「四角化と形状の優先順位」は形重視 / バランス / 数重視の3段階。きれいさを取るか、四角の数を取るかを選べます。
  • UV シーム / ハードエッジ / マテリアル境界の辺は消さずに残せます。フェースを選べば、その範囲だけを四角化することもできます。
  • ［プレビュー］で四角化後の形を色分けして重ねて表示。設定を変えるとその場で更新されるので、結果を見比べてから［実行］できます（Ctrl+Z で戻せます）。

実際の操作

起動 → メッシュを選んでプレビュー → 優先順位を切り替えて比較 → 実行、までの流れです。

動作環境

対応ソフトAutodesk Maya 2020 〜 2026（Windows）/ PySide2・PySide6 両対応（自動判別）
追加インストール不要。外部ライブラリに依存しません。
配布物zip 1ファイル（ドラッグ&ドロップインストーラ同梱）

入れかた

Maya を起動し、zip を展開したフォルダの install_MYS_CQuad.py をビューポートへドラッグ&ドロップするだけです。ファイルのコピーとシェルフボタンの作成まで自動で行われ、再起動なしでそのまま使えます。

手動でインストールする場合の手順は、同梱の README.txt にまとめてあります。アンインストールはコピーされたファイルとシェルフボタンを削除するだけです。

承知しておきたいこと

  • 程よい四角化のため、すべてを四角にできるわけではありません。特に扇形に集まった三角（元は 5 角形以上だった面など）は、三角のまま残ります。きれいなループの流れが必要な場合は、リトポを前提にお考えください。
  • 対象は三角形の面だけです。元からある四角形・多角形の面には触れません。
  • 「数重視」は四角の数を優先するぶん、歪んだ四角も増えます。まずは「バランス」で試し、プレビューの色分けを見ながら選ぶのがおすすめです。
