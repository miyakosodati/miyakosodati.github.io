MYS PanelShot v2.13.5

選択メッシュを複数アングルから一括キャプチャし、正投影統合画像として出力
Maya 2020–2026 Windows 外部依存なし 無償・商用利用可
ダウンロード（v2.13.5）
ダウンロード・使用により使用許諾契約（EULA）に同意したものとみなされます。社外への再配布はできません。

できること

  • 選択したメッシュを複数アングルからまとめてキャプチャして、正投影統合画像として出力します（2面図 / 3面図 / 8面図 / 9面図・カスタム）。
  • カメラ角度（斜め・縦）、撮影距離はもちろん、アスペクト比（Viewport / 1:1 / 4:3 / 3:4 / 16:9 / 9:16）や解像度も指定可能です。
  • 背景は透過とベタ色を選択可能です。
  • 社外・社内監修時や、資料・記録・ポートフォリオ用の撮影を一発で！

動作環境

対応ソフトAutodesk Maya 2020 〜 2026（Windows）/ PySide2・PySide6 両対応（自動判別）
追加インストール不要。外部ライブラリに依存しません。
配布物zip 1ファイル（ドラッグ&ドロップインストーラ同梱）

入れかた

Maya を起動し、zip を展開したフォルダの install_MYS_PanelShot.py をビューポートへドラッグ&ドロップするだけです。ファイルのコピーとシェルフボタンの作成まで自動で行われ、再起動なしでそのまま使えます。

手動でインストールする場合の手順は、同梱の README.txt にまとめてあります。アンインストールはコピーされたファイルとシェルフボタンを削除するだけです。

承知しておきたいこと

  • キャプチャはビューポートの表示を基にするため、画質や表示内容（シェーディング・アンチエイリアス等）はビューポートの設定に従います。
