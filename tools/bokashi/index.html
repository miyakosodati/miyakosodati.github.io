MYS Tools / Bokashi

MYS Bokashi v1.0.0

高さ基準のグラデーションを UV に焼いて画像出力（ぼかし）
Maya 2020–2026 Windows 外部依存なし 無償・商用利用可
ダウンロード（v1.0.0）
ダウンロード・使用により使用許諾契約（EULA）に同意したものとみなされます。社外への再配布はできません。

できること

  • メッシュの高さを基準に、グループごとに異なるグラデーションを UV 空間にベイクできます（最大4グループ）。グラデーションのほかにも、UVアイランド・IDマップ・ワイヤーフレームまで、テクスチャの下地作業をこれ一本で。
  • 個別の画像出力のほか、PSDとしてまとめて出力も可能です。
  • プレビューを確認しながらパラメータを調整できます。

動作環境

対応ソフトAutodesk Maya 2020 〜 2026（Windows）/ PySide2・PySide6 両対応（自動判別）
追加インストール不要。numpy がある環境では自動で高速モード、無い環境でも標準ライブラリのみの互換モードで動作します（結果は同一）。
配布物zip 1ファイル（スクリプト2つ+アイコン。scripts フォルダへコピーするだけ）

入れかた

Maya を起動し、zip を展開したフォルダの install_MYS_Bokashi.py をビューポートへドラッグ&ドロップするだけです。ファイルのコピーとシェルフボタンの作成まで自動で行われ、再起動なしでそのまま使えます。

手動でインストールする場合の手順（scripts フォルダへのコピーとシェルフ登録コード）は、同梱の README.txt にまとめてあります。アンインストールはコピーされたファイルとシェルフボタンを削除するだけです。

承知しておきたいこと

  • Windows の「コントロールされたフォルダー アクセス」が有効な環境では、Documents への画像書き出しがブロックされることがあります。出力先をプロジェクトフォルダ等に変更するか、Maya を許可アプリに追加してください（ツール側でも書き込み不可を検出して案内します）。
