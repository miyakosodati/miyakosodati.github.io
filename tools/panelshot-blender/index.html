できること

  • モデルを複数アングルからまとめて撮影し、正投影統合画像（PNG）として出力します（2面図 / 3面図 / 8面図 / 9面図・カスタム）。
  • ビューポートの見た目のまま撮影します。シーンにカメラを作らず、作業中の視点も一切動きません。
  • 3D ビューの左下に仕上がりのプレビューを表示。出力前に構成と収まりを確認できます。
  • 斜め角・縦角、モデルの正面軸、モチーフの画面比率、アスペクト比、1 コマの解像度（最大 4096 px）を指定可能。背景は透過とベタ色から選べます。
  • 選択したもの（と子階層）だけを撮影することもできます。
  • カスタム配置は Maya 版と互換の JSON で書き出し / 読み込みでき、同じレイアウトを両方で使い回せます。
  • 表示は日本語 / English をワンクリックで切り替え。

動作環境

対応ソフトBlender 4.2 LTS 以降（4.2 LTS / 5.2 LTS で動作確認、Windows）
形式Blender 拡張機能（Extension）。追加ライブラリは不要です。
配布物zip 1ファイル（本体・LICENSE・NOTICE.txt）
場所3D ビュー › サイドバー（N キー）› MYS タブ（タブ名はアドオン設定で変更可）

入れかた

ダウンロードした zip を展開せずに、Blender のウィンドウへドラッグ&ドロップするだけです。
または、編集 › プリファレンス › アドオン を開き、右上の ⌄ メニューから「ディスクからインストール」で zip を選んでください。

インストール後、3D ビューで N キーを押してサイドバーを開き、MYS タブから使えます。アンインストールはプリファレンスのアドオン一覧から行えます。

承知しておきたいこと

  • 撮影はビューポートの表示を基にするため、画質や表示内容（シェーディングモード・照明など）はビューポートの設定に従います。
  • プレビューの「自動更新」は既定で OFF です（重いシーンで編集中の負荷を避けるため）。設定を変えたときと更新ボタンでいつでも更新でき、自動更新を ON にすると編集・選択の変更に追従します。
  • .blend が未保存のときは、ピクチャフォルダ内の MYS_PanelShot フォルダに保存します（実際の保存先はパネルに表示されます）。
  • Blender 4.1 以前には対応していません。
