MYS CSweep v3.7.1

Maya 標準の Sweep Mesh を1ウィンドウでリアルタイム操作 — CSweep の C は、Casual の C
Maya 2022–2026 Windows 外部依存なし 無償・商用利用可
ダウンロード（v3.7.1）
ダウンロード・使用により使用許諾契約（EULA）に同意したものとみなされます。社外への再配布はできません。

できること

  • Maya 標準の Sweep Mesh 機能を、Curve作成 → Sweep生成 → パラメータ調整までツール上で完結できます。Curve / Mesh を選択するだけでアトリビュートをツール上に反映するため、パラメータへのアクセス速度が跳ね上がります。
  • 生成プリセットを搭載。Sweep Default で標準生成、Sweep Hair なら髪の毛向けのテーパ付きプリセットで一発生成できます（既定値は設定ウィンドウで変更可能）。
  • 生成後はスライダーでリアルタイム調整。1ドラッグ = 1アンドゥで Ctrl+Z も安心。タイプ切替（Rectangle / Line / Arc）で固有パラメータも自動で入れ替わります。
  • ツール上で調整したパラメータも、アトリビュートエディタと完全同期します。
  • パラメータのコピー / ペーストに加え、「コピーしたパラメータで生成」で任意の生成も可能。回転・テーパカーブを含めるかもトグルで選べます。

実際の操作

カーブからスイープを生成し、タイプ切替とスライダーでリアルタイムに形状を追い込む様子（アトリビュートエディタとも完全同期）。

動作環境

対応ソフトAutodesk Maya 2022 〜 2026（Windows）/ Python 3 専用 / PySide2・PySide6 両対応（自動判別）
非対応Maya 2020 / 2021（本ツールが使用する sweepMeshCreator ノードが Maya 2022 以降の標準機能のため）
追加インストール不要。外部ライブラリに依存しません。
配布物zip 1ファイル（ドラッグ&ドロップインストーラ同梱）

入れかた

Maya を起動し、zip を展開したフォルダの install_MYS_CSweep.py をビューポートへドラッグ&ドロップするだけです。ファイルのコピーとシェルフボタンの作成まで自動で行われ、再起動なしでそのまま使えます。

手動でインストールする場合の手順は、同梱の README.txt にまとめてあります。アンインストールはコピーされたファイルとシェルフボタンを削除するだけです。

承知しておきたいこと

  • カーブ作成直後に CV（コントロールバーテックス）を選択しにくい場合は、設定ウィンドウの「CV 選択優先度」を適用してください。Maya の選択優先度を一時的に引き上げます（「元に戻す」でいつでも復元できます。プリファレンスの選択プリセット表示は「カスタム」になります）。
  • 設定ウィンドウで変更した値（Sweep Hair の既定値など）は Maya の optionVar に保存されます。「デフォルト値にリセット」で工場出荷値へ戻せます。
