MYS Weight Ichiba（壱場） v2.0.5

スキンウェイト作業ツール一式 — 5つのツールを壱場ランチャーからワンクリックで
Maya 2020–2026 Windows 外部依存なし 無償・商用利用可
ダウンロード（v2.0.5）
ダウンロード・使用により使用許諾契約（EULA）に同意したものとみなされます。社外への再配布はできません。

収録ツール

  • 壱場ランチャー — 全ツールの入口。ビューポートの邪魔をしない小さな常駐バーから、各ツールをワンクリックで起動します。
  • WeightStroke — ブラシ式ウェイト塗り。ストロークでなじませながら塗れます。
  • WeightRoller — ローラー式ウェイト塗り。転がすように面で塗り広げます。
  • WeightCanvas — ウェイトのテーブル表示 / 編集。数値で正確に確認・調整できます。
  • WeightContainer — ウェイトのエクスポート / インポート。保存・流用・受け渡しに。
  • WeightMirrorChecker — 左右ミラーの差分チェック。対称崩れを素早く発見します。

壱場ランチャーの動き

動作環境

対応ソフトAutodesk Maya 2020 〜 2026（Windows）/ PySide2・PySide6 両対応（自動判別）
追加インストール不要。外部ライブラリに依存しません。
配布物zip 1ファイル（ドラッグ&ドロップインストーラ同梱・ツール一式入り）

入れかた

Maya を起動し、zip を展開したフォルダの install_MYS_WeightIchiba.py をビューポートへドラッグ&ドロップするだけです。ツール一式のコピーと「壱場」シェルフボタンの作成まで自動で行われ、再起動なしでそのまま使えます。

手動インストールの手順や、各ツールを直接起動するシェルフボタンの作り方は、同梱の README.txt にまとめてあります。アンインストールはコピーされたフォルダ・ファイルとシェルフボタンを削除するだけです。

承知しておきたいこと

  • 上書きインストールでは、旧バージョンのファイルがフォルダ内に残ることがあります。クリーンに入れ直したいときは、先にスクリプトフォルダの MYS_WeightIchiba フォルダを削除してください。
